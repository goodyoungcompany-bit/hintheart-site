Política de privacidad

Última actualización: 5 de noviembre de 2026

Esta política de privacidad explica cómo el sitio web de Hint Heart y su aplicación asociada tratan los datos, también en relación con el uso de la API de Pinterest.

Quiénes somos

Hint Heart es una marca infantil independiente con un personaje propio. Este sitio web lo opera la persona responsable de la marca Hint Heart; véase el Aviso legal. Contacto: hintheart8@gmail.com

Visita a este sitio web

Este sitio web se aloja en GitHub Pages (GitHub, Inc., EE. UU.). Al visitarlo, el proveedor de alojamiento trata datos técnicamente necesarios, como la dirección IP, la fecha y la hora, el archivo solicitado y el tipo de navegador, en archivos de registro del servidor. La base jurídica es nuestro interés legítimo en un funcionamiento seguro y estable (art. 6.1.f RGPD). En este sitio web no utilizamos cookies de seguimiento ni herramientas de análisis. Las fuentes tipográficas se sirven desde nuestro propio servidor, por lo que no se establece ninguna conexión con Google.

Lista de libros y redirecciones (go.hintheart.com)

Al abrirse, esta página carga la lista de libros (título, portada, enlaces) desde nuestro propio servicio go.hintheart.com (alojamiento: Railway; base de datos: Supabase). Por motivos técnicos, su dirección IP se transmite a este servicio.

Si abre un enlace de compra nuestro (go.hintheart.com/…/buy/…) o la página que hay tras el código QR de uno de nuestros libros, contamos la visita de forma anónima: tipo de visita, libro, origen (por ejemplo, la red social de la que procede el enlace) y país. Para ello no guardamos su dirección IP ni cookies. Para redirigirle a la tienda de Amazon adecuada de su país, su dirección IP se envía brevemente al servicio de geolocalización ip-api.com, que devuelve el país. La base jurídica es nuestro interés legítimo (art. 6.1.f RGPD) en dirigir a los visitantes a la tienda correcta y en entender el alcance de nuestras publicaciones.

Formulario de contacto

Si nos escribe a través del formulario de contacto, tratamos su nombre (opcional), su dirección de correo electrónico y su mensaje para responder a su consulta. El mensaje se guarda en nuestra base de datos (Supabase) y se nos reenvía por correo electrónico; el envío se realiza a través del servicio de correo Resend (EE. UU.). Eliminamos los mensajes como máximo a los seis meses, salvo que existan obligaciones legales de conservación. Para proteger el formulario contra abusos, su dirección IP se mantiene brevemente en la memoria y no se guarda. La base jurídica es nuestro interés legítimo en responder a las consultas y proteger el formulario contra abusos (art. 6.1.f RGPD) o, si su consulta se refiere a un contrato, el art. 6.1.b RGPD. Facilitar sus datos es voluntario, pero sin una dirección de correo electrónico no podemos responder.

Enlaces a terceros

Este sitio web enlaza con Amazon y con nuestros perfiles en Instagram, Facebook, Pinterest, TikTok y YouTube. Solo abandona nuestro sitio cuando hace clic en uno de esos enlaces; a partir de ese momento se aplican las políticas de privacidad del proveedor correspondiente.

API de Pinterest

No recopilamos datos personales de usuarios de Pinterest. Nuestra aplicación utiliza la API de Pinterest únicamente para publicar nuestro propio contenido original (imágenes y descripciones) en nuestra propia cuenta de empresa de Pinterest. Los datos que obtenemos a través de la API, como los identificadores de pines o tableros, se refieren solo a nuestra propia cuenta y se conservan únicamente el tiempo necesario para crear y gestionar esos pines.

Utilizamos estos datos exclusivamente para crear, actualizar y gestionar pines en nuestro propio tablero de Pinterest como parte de nuestra producción automatizada de contenidos. No se usan para publicidad, elaboración de perfiles ni análisis por parte de terceros. No vendemos, revendemos ni redistribuimos contenido de Pinterest ni datos derivados de Pinterest a terceros.

Si nuestra aplicación se desconecta de Pinterest, dejamos de acceder de inmediato a la API de Pinterest y eliminamos todos los tokens de acceso de Pinterest almacenados localmente que pertenezcan a nuestra cuenta.

YouTube y API de Google

Nuestra aplicación también utiliza la YouTube Data API (una API de Google) para subir y gestionar nuestros propios vídeos originales en nuestro propio canal de YouTube. A través de esta API solo accedemos a datos de nuestro propio canal (como identificadores de vídeo y estado de la subida). No accedemos a datos personales de otros usuarios de YouTube, ni los recopilamos ni los tratamos. Utilizamos estos datos exclusivamente para publicar y gestionar nuestro propio contenido como parte de nuestra producción automatizada de contenidos; nunca se venden ni se comparten con terceros. El uso que Hint Heart hace de la información recibida de las API de Google cumple la Google API Services User Data Policy, incluidos los requisitos de uso limitado (Limited Use). Si nuestra aplicación se desconecta de Google, dejamos de acceder a la API y eliminamos todos los tokens de acceso de Google/YouTube almacenados que pertenezcan a nuestra cuenta.

Sus derechos

Tiene derecho de acceso, rectificación, supresión y limitación del tratamiento de sus datos personales, a la portabilidad de los datos y a oponerse a los tratamientos basados en el interés legítimo (arts. 15 a 21 RGPD). Además, puede presentar una reclamación ante una autoridad de protección de datos. Para ejercer sus derechos, escríbanos al correo electrónico indicado abajo.

Contacto
